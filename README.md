# vim-assembly

## Summary

> Vim syntax highlighter for Legacy IBM assembly languages.

This plugin supports the following file extensions:

- `.S`: IBM S360/S370/Z390 Assembly
- `.F`: IBM S360/S370/Z390 Assembly

## How to install:

### Manualy:
In your system's Vim folder add the respective `.vim` files to the proper parent folder as shown in this repository.

### VIM Plug:
Add the line: `Plug 'The-Big-Brown-Bear/vim-assembly'` to your .vimrc, and call `PlugInstall`.
